Install it in three steps

  1. Tap the download button. Your browser saves Kuro-tv-5.72.apk.
  2. Allow the install. Android asks whether your browser may install apps. Allow it once — that prompt is Android protecting you, and it appears for every app installed outside Play Store.
  3. Confirm. Android's own installer appears; tap install. Kuro cannot skip that screen, and it never installs anything silently.

Already on an older Kuro? Install straight over it — do not uninstall first. Same package, same signing key, higher version code, so your profiles, watch list, history and logins stay put.

What's new in 5.72

  • Resume where you stopped. Continue Watching offers Resume only when the player really reported a position and accepts a seek; otherwise you get Restart, not a jump to nowhere.
  • Anime and History artwork, separately. Dim and Soften each have their own setting per profile, with a live preview and Apply / Cancel.
  • Fit and crop, on Kuro's own surface. The picture no longer shifts in places Kuro can't control.
  • Updates inside the app. Three quiet notices, then Kuro downloads the update itself and hands it to Android's installer. No browser trip, no GitHub page, no "remind me later".

Get future updates automatically

Kuro checks this repository's latest release itself and offers updates in-app — you don't need anything else.

If you'd rather track releases from outside the app, add github.com/Lovelycrxshx/Kuro-tv-Releases to Obtainium and it will follow every future version for you.

Known issues in 5.72

  • Update notices need notification permission. On Android 13+, Kuro only asks when News alerts, error alerts or RPC notifications are switched on. If you never saw a prompt, allow notifications for Kuro in Android settings.
  • The status-bar icon may look like a plain white shape instead of the logo. Text and tapping are unaffected.
  • Timing is approximate. Notices are about a day apart, but Android can delay background work well beyond that.

Questions

Is Kuro on the Play Store?

No. Kuro is distributed from this page and from GitHub Releases. That's why Android shows its "unknown app" prompt — it's a normal consequence of installing outside a store, and you're seeing the same signed file every other user gets.

Will updating wipe my data?

No. Every release is signed with the same key and shares the package name app.lovelycrxshx.kuro. Install over the old version and your profiles, watch list, history, gallery and logins remain. Uninstalling is the only thing that removes them.

Can it install updates by itself?

No, and no Android app can. Kuro can download and verify an update in the background, then open Android's installer — you still confirm on Android's own screen.

What are the source files for?

Transparency. Kuro-tv-5.72-Source.zip (15.38 MiB) is the complete tree and Kuro-tv-5.72-Source.txt (23.24 MiB) is the same tree in one text archive, for anyone who wants to read the code that handles their data.

Does it work on my phone?

Android 8.0 (API 26) or newer, and any of the four included CPU architectures — so essentially every Android phone from 2017 onward. iPhones are not supported.
